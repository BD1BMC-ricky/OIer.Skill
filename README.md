# oier — OI 竞赛码风 Skill

让 AI 写出的 C++ 算法题代码具有中国信息学竞赛选手（OIer）的真实码风，而不是默认的工程化风格。

## 这是什么

AI 默认生成的 C++ 代码带有浓重的工程味：分开 include 标准头、`std::` 前缀、驼峰长命名、满屏解释性注释、class 封装、防御式输入校验……这些放在题解里一眼假。本 skill 把 OIer 的真实编码习惯整理成规则，装上之后，AI 写算法题时会自动切换成竞赛码风。

## 触发场景

安装后，以下请求会自动应用本 skill：

- 写洛谷 / Codeforces / AtCoder / NOIP / CSP / NOI 等平台的题解代码
- 涉及数据结构、图论、DP、字符串等算法题的 C++ 代码编写
- 明确要求"OI 风格""竞赛码风""像 OIer 一样写代码"
- 把已有代码改写成竞赛风格

## 核心规则速览

| 方面 | 规则 |
|---|---|
| 头文件 | 只用 `#include <bits/stdc++.h>` + `using namespace std;` |
| 结尾 | `main` 最后必须 `return 0;` |
| 爆 int | 全程序需要 long long 时用 `#define int long long` + `signed main()` 搭配 |
| 注释 | 几乎不写；只在关键难点一句话点到为止 |
| 调试痕迹 | 注释掉的 `cerr` / `freopen` 是特征，按需保留 |
| 空行 | 基本不出现，代码密而整齐 |
| 空格 | 二元运算符两侧加空格，其余不加 |
| 大括号 | 单语句不打括号，用缩进代替；必须打时所有大括号一律单独成行 |
| 布尔值 | 不写 true/false，一律用 1/0 |
| 变量声明 | 全局量统一在头部；循环变量在 `for` 头部；块内变量块内声明 |
| 函数 | 定义直接写在 `main` 前，不写原型 |
| 数据组织 | 多用 `struct`，不用 class 封装 |
| 容器 | 优先 `vector`，大胆用 STL 和 `for (auto v : c)` |
| 命名 | 短：`n m k f dp vis ans mx fa dep`，函数名 `dfs solve check pushup` |

完整规则（含示例代码和反模式清单）见 SKILL.md。

## 两档输出模式

- **默认（干净版）**：只说"写个题解/代码"时，遵守全部风格规则，但不带调试痕迹和宣泄注释，适合直接提交或发题解。
- **真实版**：要求"最真实的码风""带调试痕迹"时，会保留注释掉的 `cerr` / `freopen`，调试艰难处可能极少量出现 OI 圈常见的宣泄性注释。

## 自定义

skill 提供的是默认值。如果你有个人偏好（Tab 缩进、大括号换行、宏定义习惯等），对话中直接说明即可，用户偏好优先于 skill 默认值。也可以直接编辑 SKILL.md 修改默认规则。

## 安装

在 Claude 对话中点击 `oier.skill` 文件卡片上的 **Save skill** 即可装入个人账号。
